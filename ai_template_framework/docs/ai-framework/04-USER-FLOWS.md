## Estados obrigatórios de interface
- loading
- vazio
- erro
- sucesso
- confirmação
- sem permissão

## Erros que precisam ser tratados
- falha de validação
- falha de autenticação
- falha de autorização
- falha de integração
- indisponibilidade temporária
- conflito de estado

## Pontos críticos de UX
- clareza nos formulários
- feedback após ação
- mensagens de erro compreensíveis
- prevenção de duplicidade de ação
- confirmação para ações destrutivas
